About CodeVault

A powerful, elegant solution for Base64 encoding and decoding

What is CodeVault?

CodeVault is a comprehensive web application designed to handle Base64 encoding and decoding for various file types. Built with modern web technologies and inspired by Apple and Samsung's design principles, it offers a seamless experience for developers, designers, and anyone working with encoded data.

Features

Multi-format support (Images, Videos, Audio, Documents, Archives)
Interactive file previews with custom controls
Local storage with IndexedDB for file management
Responsive design optimized for all devices
Dark and light theme support

Technology Stack

Frontend HTML5, CSS3, Vanilla JavaScript
Storage IndexedDB for persistent local storage
File Handling FileReader API, Base64 encoding/decoding
Media HTML5 Audio/Video APIs, Canvas
